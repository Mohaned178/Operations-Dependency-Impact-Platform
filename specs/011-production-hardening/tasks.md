- D3. **Settings seam** (`env` is an import-time singleton; FR-043 needs e2e suites with non-default settings):

  export const APP_CONFIG = Symbol('APP_CONFIG');
  export type AppConfig = Env;                       // type of the `env` singleton exported by env.ts
  export type AppConfigOverrides = Partial<Omit<AppConfig, 'rateLimit' | 'errorTracking'>> & {

- D6. **Throttler v6 behaviour, not API names**: before T019 read the installed `apps/api/node_modules/@nestjs/throttler/dist/throttler.guard.d.ts` and `throttler.module.d.ts`. Required behaviour: (a) the two login policies apply **only** to `POST /api/auth/login`; `refresh`, `password-change` and `import` only to their routes; `write` applies to every other `POST|PUT|PATCH|DELETE` under `/api` with no decorated policy and not exempt; reads, `/api/health/*`, `/metrics` and `POST /api/auth/logout` are never counted; (b) counting key = `req.ip` for `login-*` and `refresh`, user id for `password-change` and `import`, user id else `req.ip` for `write`; (c) an exhausted policy makes the guard throw `AppError` (`Errors.rateLimited(retryAfterSeconds)`), never `ThrottlerException`; (d) with `rateLimit.enabled === false` everything is allowed.
